## 代表项目

### 1. 公共数据治理与地区创业活力 — Staggered DID 复现

> 以地方大数据管理机构分批设立为准自然实验，完整实现 2020 年后因果推断文献的**三类主流修正估计量**。

**为什么值得看**：不是套命令，而是**先复现问题、再解决**。在合成数据上做 Goodman-Bacon 分解后发现，
「Early vs Later」（非法比较）权重高达 **71.4%**、系数为负，把真实效应 +0.012 压到 -0.0001——
**不做这个分解，研究者会误判政策毫无效应。**

- 三类估计量对照实现：Callaway & Sant'Anna / Sun & Abraham / Goodman-Bacon
- Stata `.do` 全流程：缩尾 → 基准 → 事件研究 → 平行趋势 → 稳健性 → 机制 → 异质性
- 三类安慰剂检验 + 分批次 PSM-DID（各批次用各自前置期特征，避免 post-treatment bias）
- 平行趋势联合检验 p = 0.726，估计量正确还原已知 β
- 纯 NumPy 实现 OLS + CR1 聚类稳健方差（绕开 statsmodels 的 DLL 依赖）

**技术栈**：Python · Stata · NumPy · Pandas · 因果推断

[`public-data-did`](https://github.com/myy-0529/public-data-did) · 代码 · 合成数据 · Stata 脚本

### 2. A 股行情数据清洗与因子回测流水线

> 复现量化数据分析实习中的数据工程流程，从原始日线到无前视偏差的因子数据集。

**核心是治住前视偏差**——它能让毫无 alpha 的策略在回测里表现优异，直到实盘失效。

- 交易日历对齐，避免停牌造成行错位与指标错算
- 所有信号 `shift(1)` 滞后，T 日建仓只用 T-1 及之前信息
- 数据质量报告：重复 / 缺失 / OHLC 逻辑 / 异常涨跌幅 / 交易日覆盖
- 与 Wind 等外部数据逐项交叉校验，输出差异明细供回查
- 分层回测检验因子单调性，计入双边交易成本

**诚实说明**：演示数据是随机游走，因此动量因子**没有**显著 alpha。这是刻意的——
如果随机数据能跑出漂亮 alpha，说明回测框架本身有问题。

**技术栈**：Python · pandas · NumPy · matplotlib

[`equity-quant-research`](https://github.com/myy-0529/equity-quant-research) · 代码 · 演示数据

### 3. 三元股份（600429）2024–2025 年报拆解

> 财务报表分析：利润结构、现金流、资产负债、杜邦分析四个维度，数据逐项标注年报页码。

- 定位2025 年由盈转亏主因：参股法国 HCo 公司计提 **4.97 亿元商誉减值**
- 剔除该项后测算主业归母净利润 **2.71 亿元、同比 +395%**
- 用杜邦拆解 ROE 仅 1.086% 的原因，指出净利率偏低（0.78% vs 行业 5%–8%）是主因
- 解释营收降 9.58% 而现金流反增 19.64% 的背离
